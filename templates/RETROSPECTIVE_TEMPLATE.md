# Clowder Pilot Retrospective

| Field | Value |
| --- | --- |
| Feature | JIRA-123, Feature Name. |
| Pilot date | YYYY-MM-DD. |
| Product repository | `/path/to/repository`. |
| Orchestrator model and reasoning | model, effort. |
| Risk level | R1, R2, or R3. |

## Outcome

- Final workflow outcome: completed, blocked, or failed.
- Pull request and merge evidence: link or explicit offline limitation.
- Jira closure evidence: link or explicit offline limitation.

## What Failed or Remained Unverified

## Next Smallest Improvement

Describe 1 bounded improvement, its trigger, expected effect, and how the next pilot will measure it.

## Handoff

```text
STATUS: completed | clarification-required | blocked | failed
SOURCES: exact artifact paths, links, versions, and Git revisions
OUTPUTS: this retrospective and any follow-up Features
EVIDENCE: measurements, checks, observations, and retained evidence
DECISIONS: decisions made within delegated authority
ASSUMPTIONS: assumptions that remain relevant
RISKS: unresolved or newly discovered risks
QUESTIONS: decisions required from another role or HITL
NEXT_GATE: next improvement or next pilot prerequisite
```
